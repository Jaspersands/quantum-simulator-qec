# Road to 1.0: design

Jasper approved the path on 2026-10-01 ("okay do it"): 0.5 freezes-in-waiting the parts that
cannot change after 1.0 (the API, seeding, the no-crash guarantee, tests and CI); 0.6 widens
Stim coverage and adds documentation and the crate decision; 1.0 is tagged once a release has
gone by without breaking changes. Open questions below were settled by the standing rule (do
both, or the fullest option).

## What 1.0 promises

- **A stable public API**: everything importable from `stabilizer_qec` without a leading
  underscore. Semantic versioning from 1.0: no removal or incompatible change before 2.0;
  deprecations warn for at least one minor release first.
- **Seeds reproduce**: the same seed and the same calls give the same shots on every machine,
  thread count and operating system. Across versions too, unless the changelog says otherwise.
- **No crashes**: bad input raises `ValueError` (or `TypeError` for a wrong type); an engine
  bug raises `RuntimeError` asking for a report. A Rust panic never reaches the caller as
  `PanicException`.
- **Correctness checks stay in CI**: Stim, PyMatching, `ldpc` and `beliefmatching` agreement.

## Package layout

maturin's mixed layout. The extension becomes `stabilizer_qec._core` (private, unstable: what
the repository's tools use, and how the recorded data stays reproducible); the public package is
Python in `python/stabilizer_qec/`, typed (`py.typed`), with numpy a dependency. The extension's
stub moves from `stabilizer_qec.pyi` to `python/stabilizer_qec/_core.pyi`.

Numpy conversion happens in Python (`packbits`/`unpackbits`, `bitorder="little"`): no numpy
crate, the abi3 wheel stays one wheel per platform. Heavy objects are compiled once in Rust
(pyclasses in `src/py_objects.rs`) and reused, so nothing is re-parsed per call.

## The public API

Names follow Stim, PyMatching and `ldpc` wherever there is an equivalent.

**Circuits and models**

- `Circuit(text="")`: from Stim text or a `stim.Circuit`; `Circuit.from_file(path)`; `str()` is
  Stim text; `==`; `num_qubits`, `num_measurements`, `num_detectors`, `num_observables`,
  `num_sweep_bits`; `detector_error_model(decompose_errors=False)`;
  `compile_detector_sampler(seed=None)`; `compile_m2d_converter()`.
- `DetectorErrorModel(text)`: from text or a `stim.DetectorErrorModel`; `from_file`; `str()`;
  `num_detectors`, `num_observables`, `num_errors`.
- `DetectorSampler.sample(shots, *, separate_observables=True, bit_packed=False, threads=1)`:
  `(detectors, observables)` arrays, `bool` of shape `(shots, n)` or `uint8` packed rows; with
  `separate_observables=False`, observables appended to each row (Stim's `append_observables`).
- `MeasurementsToDetectionEventsConverter.convert(measurements, sweep_bits=None, *,
  separate_observables=True, bit_packed=False)`.

**Decoders on a detector error model** (one protocol: `decode(syndrome) -> bool array` of
observable flips; `decode_batch(shots, *, bit_packed_shots=False, bit_packed_predictions=False,
return_weights=False, threads=1)`; `num_detectors`, `num_observables`):

- `Matching(dem, *, enable_correlations=False)`, also `Matching.from_detector_error_model`.
- `BeliefMatching(dem, *, max_iter=20, bp_method="product_sum", ms_scaling_factor=1.0)`;
  `decode_batch(..., return_converged=False)`.
- `BpOsd(dem, *, max_iter=10_000, bp_method="minimum_sum", ms_scaling_factor=0.0,
  osd_method="osd_cs", osd_order=7)`; `decode_batch(..., return_converged=False)`.
- `WindowMatching(dem, *, commit, buffer, mode="parallel", enable_correlations=False)`;
  `windows` (a list of `Window` named tuples); `decode_batch(..., return_timings=False)`.

A shot with no valid correction raises `ValueError` naming the shot, as PyMatching does.

**Decoders on a check matrix**, `ldpc`'s names and attributes so they drop in:
`BpDecoder(pcm, error_channel, *, max_iter=20, bp_method="product_sum", ms_scaling_factor=1.0)`
and `BpOsdDecoder(..., osd_method="osd_cs", osd_order=7)`; `decode(syndrome) -> correction`;
after a decode, `converge`, `iter` and (BP) `log_prob_ratios`. `pcm` is a dense array-like or a
scipy sparse matrix.

**Circuits generated**

- `memory_circuit(code="rotated", *, distance, rounds, noise="sd6", p, eta=0.5, basis="z")`.
- `BivariateBicycleCode("gross" | "72")`: `check_matrices()`, `logicals()`, `automorphisms()`,
  `memory_circuit(cycles, p, basis="z")`; for the gross code `gauging(operator, expanded=False)`
  and `logical_measurement_circuit(operator, basis, *, pre, merged, post, p, expanded=False)`.
- `stabilizer_qec.surgery`: `zz_measurement`, `xx_measurement`, `cnot`, `repeated_zz`, `line`.
- `stream_memory(...)`: the million-round stream, returning a `StreamResult` named tuple.

**Deprecated**: every 0.4 function and the `Decoder` and `RotatedSurfaceCode` classes stay at
the top level through 0.x, each warning `DeprecationWarning` with its replacement, and go in 1.0.

## Seeding

`DetectorSampler` draws batch `b` (64 shots) from a stream seeded by a mix of the seed and `b`,
so the shots depend only on the seed and on how many have been drawn before. `seed=None` takes
64 bits from the operating system. Successive `sample` calls continue: a call that ends mid-batch
discards the batch's remaining lanes. The deprecated `sample_b8_batch` keeps its per-thread
streams, because the recorded data was drawn with them; its docstring says so.

## Errors and panics

The Python layer calls `_core` through one wrapper that turns `PanicException` into
`RuntimeError("internal error in stabilizer-qec: … please report")`. Tests and fuzzing assert it
never fires.

## Testing

- `tests/` (pytest), run on Python 3.9 to 3.14 on Linux, macOS and Windows against the built
  wheel: every public object, shapes and dtypes, packed and unpacked agreement, seeding across
  thread counts, errors, deprecations; agreement with Stim, PyMatching, `ldpc` and
  `beliefmatching` where they install (skipped where they do not).
- Fuzzing: Hypothesis over the public API (random circuit texts from a grammar plus mutations,
  random arguments): only `ValueError`/`TypeError`. In Rust, a stable randomized test that
  drives the parsers, resolver, error model, samplers and m2d with generated and mutated input,
  and `cargo fuzz` targets in `fuzz/` that a nightly CI job runs for a minute each.

## 0.6

- Stim coverage: all single-qubit Cliffords (S, S_DAG, SQRT_X(_DAG), SQRT_Y(_DAG), H_XY, H_YZ,
  C_XYZ, C_ZYX), two-qubit Cliffords (CY, the XC*/YC*/ZC* family, SWAP, ISWAP(_DAG), CXSWAP,
  SWAPCX), Y-basis resets and measurements, inverted targets `!q`, MPP and MXX/MYY/MZZ,
  PAULI_CHANNEL_2, E/CORRELATED_ERROR (ELSE_CORRELATED_ERROR refused in error models, as Stim
  refuses it), MPAD. Each checked against Stim's error model and samples on random circuits.
- An API reference generated from the package (pdoc) and a getting-started guide, served at
  `qcompiler.jaspersands.com/api/`; a CHANGELOG and GitHub Releases from 0.5 on.
- The Rust crate: made publishable (metadata, MSRV, docs), with publishing left to Jasper's
  crates.io account; until then the Python package is the supported interface.
