# W2: the whole Stim surface — implementation plan

> For agentic workers: executed inline (no subagents), task by task, one commit each.

**Goal:** everything `stim` 1.16 offers in Python and in its CLI is in `stabilizer_qec`, with
the same names, the same arguments and the same outputs (inventory S1–S62).

**Architecture.**
- **Rust.** A new engine module `src/clifford/` holds Stim's objects as Rust types:
  - the objects: `PauliString`, `Tableau`, `TableauSimulator`, `CliffordString`, `Flow`;
  - a faithful instruction-level circuit (`ir.rs`: gate, args, encoded targets, tag,
    repeat blocks) that parses and prints Stim's text exactly, fusion included.
- **Python.** The bindings are thin. The classes are in `python/stabilizer_qec/_stim.py`,
  which does Stim's argument coercion.
- **Engine.** The engine's `Circuit` keeps its own IR for sampling and error analysis. Its
  text now comes from `ir.rs`.

**Conformance.** `tests/test_stim_doctests.py` runs every example in Stim's own docstrings
(2,221 of them) against our classes:
- `stim.` is replaced by `stabilizer_qec.` in the code and the expected output;
- it is skipped without Stim installed;
- examples whose output depends on Stim's random-number stream are listed in the test, each
  with its reason.

`tests/test_stim_differential.py` compares random objects and circuits with Stim's on every
method.

## Global constraints (from the spec)

- Checked against Stim 1.16.0. Names, argument names and defaults are Stim's.
- Each existing 1.x name keeps working.
- No `cargo fmt`. One commit per task. Push, then check CI.

## Tasks

1. **Gate table** (S9 data). `tools/gen_gate_data.py` writes `src/gate_data.rs`: all 81
   instructions, with flags, argument ranges, tableaus, unitaries, flows, inverses and
   Hadamard conjugates. `--check` runs in CI. **Done** in the first W2 commit.
2. **PauliString** (S1, S2).
   - Rust `clifford/pauli_string.rs`: phase i^k, Stim's text and product phase, unitary
     matrices.
   - `PauliStringIterator`: Stim's order from `pauli_string_iter.inl`.
   - Python `PauliString`: every constructor form, `* + / - []`, `commutes`, `weight`,
     `pauli_indices`, `before/after`, `to/from_numpy` (bit-packed too), `to/from_unitary_matrix`,
     `random`, `iter_all`, `extended_product`, `to_tableau`.
3. **Tableau** (S3, S4).
   - Rust `tableau.rs`, plus `convert.rs` for Stim's own algorithms:
     - `stabilizers_to_tableau`;
     - `stabilizer_state_vector_to_circuit`;
     - `tableau_to_circuit` (elimination, graph_state through a port of `GraphSimulator`,
       mpp_state, mpp_state_unsigned);
     - the state vector from stabilizers, with Stim's canonical phase (the first nonzero
       amplitude real and positive);
     - `unitary_to_tableau`;
     - Bravyi–Maslov random sampling.
   - `TableauIterator` is ported from `tableau_iter.inl`.
   - Python `Tableau`: all 44 members, including `to_numpy/from_numpy`.
4. **Instruction-level IR** (S10–S12, S20, S30).
   - `clifford/ir.rs`: Stim's `GateTarget` bits (qubit, `!`, X/Y/Z Pauli, `rec`, `sweep`,
     combiner).
   - Parsing with fusion of compatible neighbours, as Stim does.
   - Printing with Stim's `%g` (6 significant digits) and its spacing.
   - The engine `Circuit`'s `str()` comes from the IR, so it equals Stim's. Pickling
     carries the exact text.
   - Python `GateTarget`, `target_*`, `CircuitInstruction`, `CircuitRepeatBlock`.
   - `Circuit.__getitem__/__len__/insert/pop/clear/append_operation/append(instruction)`.
   - The DEM's own IR: `DemInstruction`, `DemRepeatBlock`, `DemTarget`, `target_*`, and
     DEM `+ * [] len append clear copy`.
5. **TableauSimulator** (S5).
   - Rust `tableau_sim.rs`, a port of `tableau_simulator.inl`: the inverse tableau,
     collapse, kickback, postselection, peeks, every gate and noise channel, MPP/SPP
     decompositions as `gate_decomposition.cc` does them.
   - Python `TableauSimulator`: all 70 members, plus `seed` and `copy(copy_rng, seed)`.
6. **Circuit transformations** (S21–S23, S27–S29).
   - `approx_equals`, `flattened`, `flattened_operations`, `decomposed`, `inverse`,
     `without_noise`, `without_tags`, `with_inlined_feedback`, `num_ticks`,
     `get_detector_coordinates`, `get_final_qubit_coordinates`,
     `count_determined_measurements`, `missing_detectors`,
     `reference_detector_and_observable_signs`, `to_tableau`.
   - DEM: `approx_equals`, `rounded`, `get_detector_coordinates`, `without_tags`,
     `to_file`.
   - The missing keyword arguments.
7. **Flows** (S8). `Flow` (text form, `*`, the copies). `has_flow`, `has_all_flows`,
   `flow_generators`, `solve_flow_measurements` and `time_reversed_for_flows`, ported from
   `circuit_flow_generators.inl`, `has_flow.inl` and `circuit_inverse_qec.inl`.
8. **Exports and searches** (S24–S26). `to_qasm` (2 and 3), `to_quirk_url`,
   `to_crumble_url`, `detecting_regions`, `likeliest_error_sat_problem` and
   `shortest_error_sat_problem` (WCNF), each identical to Stim's text.
9. **FlipSimulator and CliffordString** (S6, S7). Both are on the frame sampler's bit
   tables, with every method.
10. **Samplers** (S40–S44). `sample_bit_packed`, `sample_write`, `convert_file`, `bit_pack_result`,
    `dets_out/obs_out/prepend_observables`, `reference_sample=`, and Stim's class names.
11. **Diagrams** (S50–S53).
    - The `-html` wrappers.
    - `timeline-3d`, `matchgraph-3d` and DEM `matchgraph-3d`, as glTF the way Stim's `gltf.cc`
      writes it.
    - `interactive`, the W12 editor, first as the Crumble-format URL.
    - `filter_coords`.
12. **CLI** (S60–S62). `repl`, and `help gates/formats/<gate>/<format>` (text of our own,
    built from the gate table). Every subcommand flag is re-audited.
13. **Explain objects** (S13): every Stim attribute name on the explained-error classes.
14. **Conformance gate.** The doctest suite and the differential tests pass, and every
    excluded example is listed with its reason. The README gets a "Stim API" table, and
    `api/` is regenerated.

Each task ends with: `cargo test` and `pytest` green, then commit and push, then the branch's
CI.
