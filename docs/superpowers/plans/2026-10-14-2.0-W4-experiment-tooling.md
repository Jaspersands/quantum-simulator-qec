# 2.0 W4: experiment tooling (sinter, deltakit and qec-util analysis, subset sampling) — implementation plan

**Goal:** `stabilizer_qec.sinter` is sinter 1.16, whole, with no dependency beyond numpy (matplotlib only
to plot); `stabilizer_qec.analysis` has deltakit's and qec-util's analysis; subset sampling as qsample's.

**Architecture.**
- `python/stabilizer_qec/sinter/` is a port of sinter 1.16's source (Apache-2.0, notices kept, each file
  marked as modified). It keeps sinter's layout (`_data`, `_collection`, `_decoding`, `_command`,
  `_plotting.py`, `_predict.py`, `_probability_util.py`). Changes:
  - Stim is this package;
  - the `pymatching` decoders are this package's PyMatching API;
  - scipy's `linregress` and `leastsq` become closed forms in numpy;
  - reprs print `stabilizer_qec.sinter.`.
- This package's decoders are built in beside sinter's (`matching`, `correlated_matching`,
  `belief_matching`, `bposd`, `bplsd`, `relay_bp`, `union_find`, `color_matching`, `search`).
- 1.x's `Decoder(kind)`, `Sampler(kind)`, `decoders()`, `samplers()` and `sinter_decoders()` keep
  working, with this sinter and with sinter itself. `Decoder` and `Sampler` are also sinter's base
  classes: their default methods act only when a kind was given.
- The CLI is `stabilizer-qec sinter collect|combine|plot|predict` and `python -m stabilizer_qec.sinter`.
- `stabilizer_qec.analysis` is new code, checked against each reference's formulas.

**Check.**
- sinter's own unit tests and docstring examples, run against this port.
- Against sinter 1.16, installed: the same CSV text for the same stats, the same fits (to float
  rounding where scipy iterates), the same `predict_*` outputs, and `collect` statistically.

## Tasks

1. Port sinter: data, probability utilities (scipy-free), plotting, predict, decoding, collection,
   the CLI. Built-in decoders; the 1.x helpers. Port sinter's tests and doctests. Differential
   tests against sinter.
2. `stabilizer_qec.analysis`:
   - p_ij (exact and approximate) and a model from p_ij (D9, U5);
   - Λ fits and logical error per round, including asymmetric fits, quops prediction (D10);
   - error budgets (D11);
   - defect rates and plots (D12);
   - threshold fits (U5);
   - circuit tools (U3) and model tools (U4);
   - decoding managers (D15) and failure sampling to file (U6).
3. Subset sampling (U12): importance sampling by fault count, with upper and lower bounds; checked
   against direct sampling and the qsample paper's example.
4. CHANGELOG, README section.
