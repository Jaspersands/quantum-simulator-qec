# 2.0 W3: PyMatching's graph API — implementation plan

**Goal:** `stabilizer_qec.Matching` is PyMatching 2.4's `Matching`, whole: graphs built by hand,
from check matrices and from networkx / rustworkx as well as from models; graph queries;
every decode method; `add_noise` and `draw`; and PyMatching's command line.

**Architecture:** a port of PyMatching's `UserGraph` (`src/user_graph.rs`): nodes, edges with
fault-id sets, weights and probabilities, boundary nodes, and the five merge strategies. It
builds our sparse-blossom graph with PyMatching's own discretisation (integer weights kept,
otherwise scaled so the heaviest is 2^24 − 1, doubled), its handling of negative weights
(endpoints toggled, fault ids and weight pre-applied), of boundary nodes, and of parallel
boundary edges (lightest kept). Predictions over more than 64 fault ids come from the matched
edges. Models still decode with correlations through the existing correlated matcher.

**Check:** against PyMatching 2.4, installed: identical predictions and weights on random graphs
(signed and integer weights, boundary nodes, merges, repetitions, >64 fault ids) and on models;
identical edge and matched-detector sets wherever PyMatching's matching is unique.

## Tasks

1. `src/user_graph.rs`: the graph, merging, queries, build, decode (prediction + weight),
   decode to edges, decode to matched pairs. Rust tests.
2. Bindings (`PyUserGraph`) and `Matching` in Python: constructors (graph, check matrix with
   repetitions / timelike weights / faults matrix / virtual boundary, networkx, rustworkx,
   models, circuits, files), `add_edge` / `add_boundary_edge` with merge strategies, queries,
   `decode` / `decode_batch` / `decode_to_edges_array` / `decode_to_matched_dets_array` /
   `decode_to_matched_dets_dict`, `to_networkx` / `to_rustworkx`, `add_noise`, `draw`,
   `__repr__`; `stabilizer_qec.pymatching` (`Matching`, `set_seed`, `randomize`, `rand_float`).
3. PyMatching's CLI: `predict` and `count_mistakes` (`stabilizer-qec predict ...`, and
   `python -m stabilizer_qec.pymatching`).
4. Conformance: PyMatching's API surface and random-graph differential tests; CHANGELOG.
