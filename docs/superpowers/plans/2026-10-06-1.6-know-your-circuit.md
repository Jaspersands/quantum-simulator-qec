# 1.6 "Know your circuit" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. (This plan is executed inline, without subagents.)

**Goal:** Stim's error-explanation and circuit-distance tools, Stim's command line and result formats, Stim's text timeline, and a JOSS paper, each checked against Stim.

**Architecture:** The backward error-model walk (`src/dem_build.rs`) gains a provenance mode that records where each fault came from; `src/explain.rs` formats and filters those records as Stim does. `src/distance.rs` searches a model's faults for the smallest undetectable logical error (graph-like breadth-first search, Stim's hyperedge heuristic, and an exact integer program in Python). Result formats extend `src/shots.rs`; the CLI is a Python module over the public API. The timeline layout in `src/diagram.rs` is rewritten to Stim's.

**Tech Stack:** Rust engine (PyO3 0.29 bindings), Python package, Stim 1.16 / PyMatching 2.4 as oracles in tests, scipy's HiGHS for the integer program, pandoc-free JOSS draft via `openjournals/inara`.

- Produces: `pub fn shortest_graphlike(dem: &Dem, ignore_ungraphlike: bool) -> Result<Vec<Vec<u64>>, String>` (the faults, each as its targets); `DetectorErrorModel.shortest_graphlike_error(ignore_ungraphlike_errors=True) -> DetectorErrorModel` (every fault `error(1)`, as Stim); `Circuit.shortest_graphlike_error(*, ignore_ungraphlike_errors=True, canonicalize_circuit_errors=False) -> list[ExplainedError]`; Rust `DetectorErrorModel::shortest_graphlike_error`, `Circuit::shortest_graphlike_error`.

Algorithm (Stim's): split every fault into its graph-like components (decomposed `^` pieces; with `ignore_ungraphlike_errors=False` a component of 3+ detectors is an error); nodes are detectors plus a boundary; a breadth-first search over states `(node, observable mask)` starting from every edge's endpoints finds the shortest path from `(v, 0)` to `(v, m ≠ 0)` (or boundary to boundary with `m ≠ 0`); its edges are the faults. Equal-length ties may differ from Stim's choice.

```python
# tests/test_distance.py
import pytest
import stabilizer_qec as sq

stim = pytest.importorskip("stim")

CASES = [(t, d) for t in ["repetition_code:memory", "surface_code:rotated_memory_x", "surface_code:rotated_memory_z", "surface_code:unrotated_memory_z", "color_code:memory_xyz"] for d in (3, 5)]


def undetected_logical(dem_text):
    """The faults' symptoms cancel and flip an observable."""
    dets, obs = set(), set()
    for line in dem_text.splitlines():
        if line.startswith("error"):
            for t in line.split(")", 1)[1].replace("^", " ").split():
                (dets if t[0] == "D" else obs).symmetric_difference_update({t})
    return not dets and bool(obs)


@pytest.mark.parametrize("task,d", CASES)
def test_graphlike_distance_equals_stims(task, d):
    c = stim.Circuit.generated(task, distance=d, rounds=d, after_clifford_depolarization=0.001, before_measure_flip_probability=0.001)
    ours = sq.Circuit(str(c))
    model = ours.detector_error_model(decompose_errors=True)
    found = model.shortest_graphlike_error()
    assert found.num_errors == len(c.shortest_graphlike_error())
    assert undetected_logical(str(found))
    assert len(ours.shortest_graphlike_error()) == found.num_errors
```

(`color_code:memory_xyz` is not graph-like; it is tested with `ignore_ungraphlike_errors=True` as Stim does.)
