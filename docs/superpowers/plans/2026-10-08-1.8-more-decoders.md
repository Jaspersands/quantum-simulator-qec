**Goal:** Four decoders the field compares against — BP+LSD, Relay-BP, Chromobius-style colour-code matching and a Tesseract-style search — each checked against its authors' package, added to the Rust API, the Python API and sinter, and released as 1.8.0.

**Architecture:** Each decoder is one engine module under `src/`, built on the pieces already there: `bp.rs` (BP's arithmetic, `ldpc`'s), `osd.rs`, the sparse matcher (`src/sparse`, its `decode_to_edges`) and the flat model (`DetectorErrorModel::flat`). Every decoder that has a reference is ported from the reference's own source (read under `$S/ref/`, see below) with its order of operations kept, so results can be held equal shot for shot, not just statistically. Where the reference's choices depend on something unportable (hash-set order of pointers, `std::sort` or `std::priority_queue` among equal keys), ours makes a fixed choice and the check tool counts those shots as ties, proving each is one.

**Tech Stack:** Rust engine (`--target aarch64-apple-darwin` for native timing), pyo3 bindings, Python wrappers in `python/stabilizer_qec/_decoders.py`. References: `ldpc` 2.4.1 (installed), `chromobius` 1.1.1, `tesseract-decoder` (pre-release wheels only: `pip install --pre`), `relay-bp` 0.2.2 (sdist with Rust source; builds with maturin; Linux cp314 wheel only).

#[cfg(test)]
mod tests {
    use super::*;
    use crate::surface_code::Xorshift;

    fn random(m: usize, n: usize, rng: &mut Xorshift) -> Vec<Vec<u32>> {
        (0..n).map(|_| { let mut c: Vec<u32> = (0..m as u32).filter(|_| rng.next_f64() < 0.3).collect(); c.dedup(); c }).collect()
    }
    fn apply(csc: &[Vec<u32>], x: &[u8], m: usize) -> Vec<u8> {
        let mut y = vec![0u8; m];
        for (j, col) in csc.iter().enumerate() { if x[j] == 1 { for &r in col { y[r as usize] ^= 1; } } }
        y
    }

    /// lu_solve after a full rref solves every syndrome in the image, with pivots only.
    #[test]
    fn full_rref_solves_the_image() {
        let mut rng = Xorshift::new(3);
        for _ in 0..200 {
            let (m, n) = (1 + (rng.next_u64() % 12) as usize, 1 + (rng.next_u64() % 16) as usize);
            let csc = random(m, n, &mut rng);
            let x: Vec<u8> = (0..n).map(|_| u8::from(rng.next_f64() < 0.4)).collect();
            let y = apply(&csc, &x, m);
            let mut p = Plu::new(m, n, csc.clone());
            p.rref();
            let s = p.lu_solve(&y);
            assert_eq!(apply(&csc, &s, m), y);
            assert!(s.iter().enumerate().all(|(j, &b)| b == 0 || p.pivot_cols.contains(&(j as u32))));
        }
    }

    /// The image check agrees with brute force, and columns added one at a time with the check
    /// resumed from where it stopped give the same answer as starting over.
    #[test]
    fn image_check_is_exact_and_resumable() {
        let mut rng = Xorshift::new(4);
        for _ in 0..200 {
            let (m, n) = (1 + (rng.next_u64() % 8) as usize, 1 + (rng.next_u64() % 8) as usize);
            let csc = random(m, n, &mut rng);
            let y: Vec<u8> = (0..m).map(|_| u8::from(rng.next_f64() < 0.5)).collect();
            let in_image = (0u32..1 << n).any(|mask| apply(&csc, &(0..n).map(|j| (mask >> j & 1) as u8).collect::<Vec<_>>(), m) == y);
            let mut p = Plu::new(m, n, csc.clone());
            assert_eq!(p.rref_with_y_image_check(&y, 0), in_image);
            if in_image { assert_eq!(apply(&csc, &p.lu_solve(&y), m), y); }
        }
    }
}

- Produces: `RobinSet` (`new()`, `insert(u32) -> bool`, `remove(u32) -> bool`, `contains`, `iter()` in tsl's bucket order, `len`, `clear`); `crate::lsd::{Lsd, LsdWork, BpLsd as EngineBpLsd}` with `BpLsd::new(num_checks, columns, priors, method, max_iter, lsd_method: OsdMethod, lsd_order, bits_per_step, always_run) -> Result<_, String>`, `work()`, `decode(&syndrome, &mut work) -> BpOsdOutcome-like {converged, iterations}` leaving `work.correction`; `pub fn syndrome_shots<D: SyndromeDecoder>(...)` in `batch.rs` replacing `bposd_shots`'s body (BP+OSD keeps its name as a thin call); the Rust and Python names in the Names section.

Why the robin set: ldpc keeps every cluster's bits, checks, boundary and candidates in `tsl::robin_set<int>`, and the order it iterates them decides the order columns enter the cluster matrix when clusters merge, and which candidate wins a tie. `std::hash<int>` is the identity on both libc++ and libstdc++, so that order is a pure function of the insertions and erasures: power-of-two bucket arrays (growth ×2, max load factor 0.5, first allocation on first insert), robin-hood insertion by distance from the ideal bucket (`key & mask`), backward-shift deletion, and rehash by reinserting in old bucket order. `src/robin.rs` reproduces it (read `tsl/robin_hash.h` for the exact first bucket count and rehash trigger: fetch it into `$S/ref/tsl/` from `Tessil/robin-map` at the version ldpc vendors). The merge list (`robin_set<LsdCluster*>`) hashes pointers, so its order is not reproducible: ours merges in ascending cluster id, and a step that merges three or more clusters is counted as a possible tie.

Sorting: ldpc's `sort_indices` is `std::sort` on weights; ours is a stable sort over the robin set's order. Only the first `bits_per_step` candidates are taken, so the order matters only when the smallest weights tie; `LsdWork` counts `tied_choices` (a tie at the cut) for the check tool.

The reference (`$S/ref/relay/relay_bp-0.2.2/crates/relay_bp/src/bp/{min_sum,relay}.rs`) is memory min-sum: each check sends the scaled minimum (`<=` comparisons for the two smallest, sign by XOR) to each variable; each variable's prior is `(1 − γᵥ)·λᵥ + γᵥ·Λᵥ` with `Λᵥ` its last posterior (only when `gamma0` is set); a variable is set when its posterior is at most 0. Relay: one leg of `pre_iter` iterations with every γ = `gamma0`; then up to `num_sets` legs of `set_max_iter` iterations, each with fresh γ drawn per variable from `Uniform(gamma_dist_interval)` (or the explicit gammas' row `leg % rows`), messages reset but posteriors carried over; a converged leg's quality is the weight `Σ λᵥ` over its correction (read `decoder.rs`'s `get_decoding_quality`), the lowest kept; stop after `stop_after` converged legs. Ported with its float arithmetic in its order (f64, the `N = f64` instantiation).
