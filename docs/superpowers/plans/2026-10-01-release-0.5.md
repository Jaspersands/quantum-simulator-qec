# Release 0.5 Implementation Plan

> Executed inline (superpowers:executing-plans), on branch `feature/api-0.5`, one commit per task.

**Goal:** the 1.0-shaped public API, reproducible seeding, the no-crash guarantee, a pytest suite
on Python 3.9–3.14 × three operating systems, and fuzzing; released as 0.5.0.

**Spec:** `docs/superpowers/specs/2026-10-01-road-to-1.0-design.md`.

## Global constraints

- The repository's tools import `stabilizer_qec._core as sq` and keep producing the recorded data
  bit for bit (old seeding stays in `_core.sample_b8_batch`).
- Python 3.9 syntax in the package (`from __future__ import annotations`, no `match`).
- One abi3 wheel per platform; numpy is the only new runtime dependency.
- Build: `VIRTUAL_ENV=$PWD/.venv-f CARGO_TARGET_DIR=target-f .venv-f/bin/maturin develop --profile python`.
- Report rebuilds use the system `python3` (matplotlib 3.10.0).

### Task 1: Package layout

Files: `pyproject.toml` (python-source, module-name `stabilizer_qec._core`, numpy dependency,
classifiers), `src/lib.rs` (`#[pymodule] fn _core`), `python/stabilizer_qec/__init__.py`
(deprecated top-level forwarding via module `__getattr__`), `python/stabilizer_qec/py.typed`,
`stabilizer_qec.pyi` → `python/stabilizer_qec/_core.pyi`, every tool's import, `.gitignore`.
Test: `tools/smoke.py` passes against `_core`; `import stabilizer_qec; stabilizer_qec.generate_circuit(...)`
warns `DeprecationWarning` and still works.

### Task 2: Compiled objects in Rust

File: `src/py_objects.rs`, registered in `_core`: `Circuit`, `Dem`, `Sampler` (per-batch
streams), `M2d`, `Matcher`, `BeliefMatcher`, `DemBpOsd`, `Bp`, `BpOsd`, `WindowMatcher`, all
taking and returning b8 bytes, releasing the GIL. Rust test: shots identical for 1, 3 and 8
threads and across split calls.

### Task 3: The public Python layer

Files: `python/stabilizer_qec/{_util,circuit,decoders,codes,surgery}.py`, `__init__.py` exports.
Panic mapping in `_util.call`. Test: `tests/` (Task 4) drives it.

### Task 4: pytest suite

Files: `tests/conftest.py`, `tests/test_{circuit,sampler,m2d,matching,bp,codes,errors,deprecated}.py`.
Cross-checks with Stim, PyMatching, `ldpc`, `beliefmatching` via `pytest.importorskip`.

### Task 5: Fuzzing

Files: `src/fuzz_tests.rs` (stable, randomized, `#[cfg(test)]`), `fuzz/` (cargo-fuzz targets
`circuit`, `dem`), `tests/test_fuzz.py` (Hypothesis). Fix what they find, each with a test.

### Task 6: CI

`.github/workflows/ci.yml`: build the wheel once per OS, test it on Python 3.9–3.14; a nightly
fuzz job; the existing Rust, site and cross-check jobs kept.

### Task 7: Release

Version 0.5.0, `CHANGELOG.md`, README quick start on the new API, `python/README.md`,
`tools/smoke.py` on the public API, report rebuilt; merge, tag `v0.5.0`, GitHub Release, verify
PyPI from a fresh virtualenv.
