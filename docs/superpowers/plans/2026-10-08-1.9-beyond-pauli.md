**Goal:** Sample and decode Stim circuits under coherent errors at circuit level and at large
distance, which no released tool does, checked exactly against a state-vector oracle. Plus
Stim-readable leakage. Release as 1.9.0.

**Architecture:**
- `src/nonpauli.rs` parses the tagged identity instructions (`I_ERROR[R_Z(theta=…)]` and the
  rest) into typed operations. `resolve` keeps them in the flat instruction stream as a new
  `Instr::NonPauli`, which every Clifford engine ignores.
- `src/statevec.rs` is the exact oracle.
- `src/coherent/` holds the new sampler:
  - `locations.rs`: coherent locations, flip vectors, exact merging;
  - `kernel.rs`: spacetime kernel generators and their signed operators;
  - `exact.rs`: the exhaustive enumerator used by tests;
  - `sampler.rs`: the two-frame sampler with per-shot weights.
- `src/leakage.rs` adds the leaked flag to the per-shot frame sampler.
- `src/api/` gets the Rust facade; the Python wrappers live in `python/stabilizer_qec/_coherent.py`.

**Tech Stack:** Rust engine, no new dependencies (complex numbers as `(f64, f64)` in a small
local type). pyo3 bindings, numpy. Python oracle cross-checks use numpy dense matrices in tests
only.

## Method reference (the derivation the code implements)

### Amplitudes

A coherent location k applies exp(−iθ_k P_k) = c_k I − i s_k P_k, with c = cos θ, s = sin θ and
t = tan θ. A fault set F has amplitude a_F = Π_{k∈F}(−i s_k) Π_{k∉F} c_k.

### Purified picture

- A measurement is a CNOT onto a fresh ancilla.
- A reset is a hidden measurement followed by swapping in a fresh |0⟩.
- The circuit ends with a hidden Z measurement of every qubit.
- X-basis operations are conjugated by H.

### Twirl

q(F, m) = |a_F|² p₀(m′), where m′ = m ⊕ x_F is the noiseless-branch record (hidden outcomes
included). The frame sampler draws (F, m′) from q when location k fires P_k with probability s_k².

### Kernel

G is a kernel element when the forward-accumulated signed operator E_G has no X component at any
measurement, reset or the final hidden measurement. To build E_G:
- start at +I;
- at each location g ∈ G, set E ← P_g E;
- at each Clifford U, set E ← U E U†, with signs;
- at a reset or the final hidden measurement, a Z component on the qubit is absorbed: record its
  hidden-outcome index in z_G and drop it;
- at a plain M, a Z component stays.

The leftover scalar is σ_G ∈ {±1, ±i}.

### Ratio

ratio_G(F, m′) = Π_{g∈G∖F}(i t_g) · Π_{g∈G∩F}(−i/t_g) · (−1)^{Σ_g a_g(F)} · conj(σ_G) · (−1)^{m′·z_G}.

Here a_g(F) says whether P_g anticommutes with the shot's fault-only frame just before location g.
That frame holds the stochastic and coherent faults that fired, with no randomisation. A reset
clears the frame's components on the reset qubit.

### Weight

w(F, m′) = 1 + Σ_{G≠∅} f_G(F) · Re ratio_G. The factor f_G is:
- 2 when Π_{added} t² < Π_{removed} t² (F′ is the less likely side);
- 1 on a tie, within 1e-12 relative;
- 0 otherwise.

E_q[1{outcome} · w] is the true probability when G ranges over the whole kernel. The estimate
is p̂ = Σ f·w / Σ w (self-normalised).

### Limits

The coherent sampler rejects, with an error naming the line:
- feedback;
- sweep bits;
- observables with Pauli targets;
- non-Pauli tags other than the coherent rotations.

## Names (fixed here; later tasks use exactly these)

### Rust

- `nonpauli::NonPauli` is an enum with these variants:
  - `Rotation { pauli: Vec<(u32, Pauli)>, theta: f64 }`;
  - `T { qubit, dagger }`;
  - `U3 { qubit, theta, phi, lambda }`;
  - `Leak { p, qubit }`;
  - `Seep { p, qubit }`;
  - `LeakTransport { p, a, b }`;
  - `AmplitudeDamping { gamma, qubit }`.

  `nonpauli::parse(name, tag, targets) -> Result<Option<Vec<NonPauli>>, String>` returns `None`
  for an unknown tag.
- `Instr::NonPauli(Vec<NonPauli>)` appears in resolved streams only.
- `statevec::StateVector::new(n)`; `statevec::ExactSampler::new(&Circuit, seed)`, with
  `.sample(shots) -> (Vec<u8> dets b8, Vec<u8> obs b8)`.
- `statevec::exact_distribution(&Circuit) -> BTreeMap<(Vec<bool>, u64), f64>` (≤ 20 qubits,
  branching over outcomes).
- `coherent::CoherentOptions::new()` with `.order(Option<usize>)`, `.merge(bool)` and
  `.max_kernel(usize)`.
- `coherent::CoherentSampler::new(&Circuit, CoherentOptions) -> Result<_, String>`, with
  `.sample(seed, shots) -> CoherentBatch { dets, obs, weights: Vec<f64> }`.
- `coherent::exact::distribution(&Circuit, CoherentOptions)` returns the same map type as the
  state vector's.
- `coherent::merged_circuit(&Circuit) -> Circuit` is the twirl after exact merging, written as
  Pauli channels.

### Rust API

- `Circuit::compile_coherent_sampler(CoherentOptions) -> Result<CoherentSampler>`;
- `Circuit::compile_exact_sampler(seed)`;
- `Circuit::twirled()` and `Circuit::twirled_merged()` return Circuits whose rotations become
  Pauli channels.

### Python

- `Circuit.compile_coherent_sampler(*, order=2, merge=True, seed=None)` returns an object with
  `.sample(shots, separate_observables=True)` → `(dets, obs, weights)`.
- `Circuit.compile_exact_sampler(seed=None)` returns an object with `.sample(shots, separate_observables=True)`.
- `Circuit.twirled(merge=False)`.
- `stabilizer_qec.weighted_logical_error_rate(decoder, dets, obs, weights)` returns
  `(rate, stderr)`.

## Outcome (2026-10-09)

Tasks 1–8 were built as planned, with these departures. The spec's "As built" section has the
method's details.

- **Task 3: the kernel.**
  - The kernel needed gauge generators: the frame's randomisation points.
  - Equivalence groups replaced exact merging. They are drawn as one, from their coherent parity
    mixed 90/10 with the twirl's.
  - Clusters reach one step past the touched generators, and products are over connected sets.
- **Task 4: the weight** became the class weight |1 + Σr|² / (1 + Σ|r|²). It is never negative,
  and it is exact on every branch of 150 random circuits. The local kernel is exact on 80 more.
- **Task 6:** sinter integration was dropped. The weighted-rate helpers serve instead.
- **Task 7: leakage** runs in the per-shot frame sampler, with heralds and Google's partner
  model, and in the state vector. The two agree. Leakage-aware decoding is not in 1.9.
- **Rust API:** done in Task 8 rather than Task 2.
- **Fuzzing** caught a real bug: a tagged operation's qubits were not counted. `Instr::qubits` now
  includes them.

Results (`data/coherent/`):
- Against exact answers, the sampler agrees within its error bars on six repetition codes and on
  the d = 3 surface code at two angles. The twirl is 5–10× low on the same circuits.
- At circuit level (X memory, p = 0.2%, Z over-rotation after every tick) the twirl
  underestimates the logical error by up to 12× at d = 5, θ = 0.02. The gap grows with distance
  at fixed θ: at θ = 0.01 it is 2.4× at d = 3 and 6.8× at d = 9.
- Decoding on the merged model removes up to 12% of the failures at the larger angles, and
  nothing at the smallest.
- ZZ crosstalk on every CNOT is milder: 1.1–1.5×.
- At code capacity the twirl is accurate at every d (ratio ≈ 1), as Bravyi et al. found.
- Reach: the effective sample size is ≥ 0.4 to d = 11 at θ = 0.01 per tick, and 0.06 at
  θ = 0.02.
