stabilizer_qec.estimate.azure_report

The QDK's report of an Azure estimate, for stabilizer_qec.estimate.azure.EstimatorResult: the HTML tables (_repr_html_(), summary, a batch's side-by-side [:]) beside their text, the diagrams' HTML (diagram.space, diagram.time), a batch's matplotlib plot (plot()), and the charts of the QDK's notebook widgets as SVG: the space chart (the physical qubits of the algorithm against the T factories', a donut with a side table) and the estimates overview's scatter chart (physical qubits against runtime, both logarithmic, a frontier's entries joined by a line). Each is what the QDK and qsharp_widgets draw (tests/estimate_port/qdk_reports.json.gz). With markdown and python-markdown-math installed the explanations and assumptions are converted. Deliberate safety differences from QDK 1.33.1: all result/reportData values are untrusted; text is escaped, Markdown is reconstructed using a fixed balanced formatting subset (p/em/strong/code/pre/br/ul/ol/li/blockquote/a, only absolute HTTP(S) hrefs and link titles), and diagram JSON is escaped in quoted attributes without changing spaces in its string values. Arbitrary HTML and script-style custom math containers render inert; ordinary TeX text is retained. Explicit HTML wrappers themselves remain developer-supplied HTML containers.

>>> from stabilizer_qec.estimate.azure import LogicalCounts
>>> r = LogicalCounts(num_qubits=12, t_count=500).estimate()
>>> r.summary.splitlines()[0], r["physicalCountsFormatted"]["runtime"]
('Physical resource estimates', '3 millisecs')
>>> r.space_chart().count("<path")  # the donut: the algorithm's qubits and the T factories'
2
>>> frontier = LogicalCounts(num_qubits=12, t_count=500).estimate({"estimateType": "frontier"})
>>> chart = frontier.scatter_chart()
>>> chart.startswith('<svg xmlns="http://www.w3.org/2000/svg"'), chart.count("<circle"), len(frontier["frontierEntries"])
(True, 13, 13)

def item_result_table(result) -> str:

The QDK's _repr_html_ of one result: each report group (open where always visible) with its entries' label, value and explained description, then the assumptions (listed only with markdown). A path's key the result lacks at a level is read in its first frontier entry.

def item_result_summary_table(result) -> str:

The QDK's summary of one result: the groups' entries as label (its explanation a tooltip), value and description, under the tooltips' style, then the assumptions (listed only with markdown).

def batch_result_table(result, indices: Iterable[int]) -> str:

The QDK's side-by-side table of a batch's items indices: the groups of the first succeeded item, each label once (from every succeeded item's group at that position), and each item's value, its path's keys followed as they are ("N/A" where one is missing, so for a frontier item's counts, and for a failed item). With no succeeded item the QDK prints "None of the jobs succeeded" and draws nothing. The assumptions (with markdown) are item 0's: a failed item 0 raises KeyError, as in the QDK.

The QDK's _repr_html_ of a batch: its first MAX_DEFAULT_ITEMS_IN_TABLE (5) items side by side, after a note when there are more.

def plot(result, **kwargs: Any) -> None:

Plots all result items in a space time plot, where the x-axis shows total runtime, and the y-axis shows total number of physical qubits. Both axes are in log-scale.

:param **kwargs: Common options:

- ``labels`` (list): List of labels for the legend. Defaults to ``[]``.
def time_ticks(lo: float, hi: float) -> List[Dict[str, Any]]:

The widgets' ticks of a runtime axis from lo to hi ns: the units (a nanosecond to a century) within it, else multiples of the unit below it (30 seconds), past a century of centuries.

def integer_ticks(lo: float, hi: float) -> List[Dict[str, Any]]:

The widgets' ticks of a count axis from lo to hi: the powers of ten within it, else the multiples of the largest power of ten below it that has some. Where the widget never returns (lo below 1: its first power, 10^⌊log₁₀ lo⌋ rounded, is 0, and ten times 0 is 0), the powers start at 1.

def color_map(count: int) -> List[str]:

The widgets' colors of count estimates: hues by the golden ratio, saturations by √2 and lightnesses by e, each the fractional part of the index times it, as hex.

def run_names(estimates: Sequence[Dict[str, Any]]) -> List[str]:

The widgets' names of estimates shown together: one alone is named by its shared run name, qubit or scheme; several by the fields that differ among them (shared run name, qubit, scheme, error budget), with the index added when names repeat.

class Chart(builtins.str):

A chart: the SVG document (the string itself, and _repr_svg_) and, for notebooks, its HTML (_repr_html_) with what the widget shows beside it.

def space_chart( data: Dict[str, Any], index: Optional[int] = None) -> Chart:

qsharp_widgets' SpaceChart of a result: a donut of its physical qubits, the algorithm's (orange) against the T factories' (blue), the total in the middle; in the HTML, beside it, the table of the qubits (in total, per T factory and their copies, the algorithm's logical and physical ones, per logical qubit). A frontier's entry index (the first where it is None or out of range).

def scatter_chart( estimates: Sequence[Dict[str, Any]], colors: Optional[Sequence[str]] = None, names: Optional[Sequence[str]] = None, kept: Optional[Sequence[int]] = None) -> Chart:

The estimates overview's scatter chart of results drawn together: each result's physical qubits against its runtime (a frontier's entries joined by a line), both axes logarithmic with the widgets' ticks, a color each (the widgets' color map, or colors when there are as many as estimates). The HTML has the overview's table above it: each result's color and run name (names when there are as many), T factory fraction, physical qubits, runtime and rQOPS. kept, where given, are the indices of the estimates drawn (a batch's succeeded items: the widget cannot draw a failed one). As in the widget, colors and names are counted against all of estimates, and the colors, the color map's too, are given out over all of them; those drawn keep theirs. The run names made up where names are not given are made up from those drawn (a failed item has no parameters to name).
