stabilizer_qec.tsim.zx

Tsim's ZX graphs: the graph a circuit is (Circuit.get_graph), the graph that gives the probabilities of its samples (Circuit.get_sampling_graph), the tensor of the graph and its diagrams.

parse_stim_circuit builds a GraphRepresentation (the graph, the vertices of the measurement record, the detectors and observables, the noise channels' probabilities) with Tsim's builders (instructions) on one of two backends: this package's ZXGraph ("own", nothing to install) or pyzx_param's GraphS ("pyzx_param", the graph Tsim builds, which pyzx_param's simplifier reduces); by default pyzx_param's when it imports (importing pyzx_param sets numpy's print option suppress=True for the process, as importing Tsim does). The two graphs are equal vertex for vertex, edge for edge, with phases as Fractions of pi, phase variables (rec[i] a measurement outcome, e{k} an error bit, det[i], obs[i]) as sets of names, and the same scalar.

class ZXGraph:

A ZX graph: vertices numbered by integers, each of a type (VertexType), a phase (a Fraction of pi, mod 2), a set of phase variables (names, XORed into the phase), a qubit and a row; at most one edge between two vertices, SIMPLE or HADAMARD (BOLD and HADAMARD_BOLD mark the classical wires of diagram("pyzx")); inputs and outputs; and a scalar.

add_edge applies the rules for a parallel edge as pyzx_param does: two fusing edges are one; a fusing and a Hopf edge leave the fusing one, a pi on one end and a factor of 1/sqrt(2); two Hopf edges cancel, with a factor of 1/2. A self-loop of a Z or X spider is dropped (a Hadamard one adds a pi).

def squash_graph(g: Any) -> None:

Compact the graph by placing vertices underneath their output connections.

Starting from output vertices, each vertex is placed directly underneath (same row, qubit - 1) its already-placed neighbor. Positions are assigned via BFS traversal from outputs, ensuring no (qubit, row) collisions.

def tensorfy(g: Any, preserve_scalar: bool = True) -> numpy.ndarray:

The tensor of a graph: a complex array of shape (2,) * (outputs + inputs), the output indices first, each in the order of g.outputs() and g.inputs(), times the scalar if preserve_scalar.

Raises ValueError for a vertex that is not a Z or X spider or a boundary, a boundary that is not an input or output, an output that is not a leaf, and a spider of more than 2^24 entries (24 legs) or an intermediate tensor of more than 2^26 (1 GiB of complex128, which tensordot copies), instead of allocating it.

def transform_error_basis(g: Any, num_e: Any = None) -> Tuple[Any, numpy.ndarray]:

Transform phase variables from the original 'e' basis to a reduced 'f' basis.

This function finds a linearly independent basis for the phase variables across all vertices and transforms them accordingly. The original variables (e0, e1, ...) are mapped to a smaller set (f0, f1, ...) where each f_i corresponds to a linear combination of original e variables.

Args: g: A ZX graph with phase variables attached to vertices. num_e: Total number of e-variables. If provided, the returned matrix will have exactly this many columns (padded with zeros if needed). If None, the matrix will have only the columns that appear in the graph.

Returns: A tuple containing: - The modified graph (same object, mutated in place) - A binary matrix of shape (num_f, num_e) where entry [i, j] = 1 means f_i depends on e_j. For example, if row 0 is [0, 1, 0, 1], then f0 = e1 XOR e3.
