stabilizer_qec.cudaq_qec

CUDA-Q QEC under its names (import stabilizer_qec.cudaq_qec as qec): the decoder interface (get_decoder, Decoder, DecoderResult, BatchDecoderResult, the @decoder registry), its decoders (single- and multi-error lookup tables, PyMatching, the sliding window, nv-qldpc-decoder, Chromobius, nv-fusion-decoder, the tensor-network decoder, trt_decoder (its ONNX model run on the CPU), the examples), its detector error model (and the extended one: chunks with named seams, stitched and closed, the dem_chunks of a repeated-round experiment, and the DEM of CSS code matrices), dem_sampling and its parity-check-matrix tools; its codes (get_code: the surface code in its orientations XV, XH, ZV and ZH, with its stabilizer_grid and CNOT schedules, Steane's and the repetition code, @code for Python ones) and its experiments on them (memory circuits sampled or made detector error models, under its noise models; code-capacity samples); and its real-time decoding host library (decoder_config / multi_decoder_config and their YAML, the decoder parameter schemas, configure_decoders, enqueue_syndromes, get_corrections, reset_decoder, finalize_decoders). Its kernels are this package's circuits (memory_circuit; kernels registered for a Python code are not run, and say so); CUDA-Q's own kernels and its GPU decoders' engines (a TensorRT engine file, CUDA graphs) need CUDA-Q itself and are not here.

def configure_decoders(decoders, *, workers: int = 1):

Configure real-time decoders. From a multi_decoder_config, as CUDA-Q: the decoders it describes replace those configured before, and the status (0 when all were built) is returned. Or this package's queue form: decoders a dict {id: decoder} or a list (numbered from 0) of any decoders with decode_batch or decode (this package's, or a Decoder), each put behind a queue of workers threads; returns their ids.

def enqueue_syndromes(decoder_id, syndromes, tag=None):

Send a decoder syndromes. A decoder configured from a multi_decoder_config takes a round of measurement bits (tag labels the call), decoding once its shot's have all arrived. A queued decoder takes a batch of detector syndromes and returns the batch's ticket.

def get_corrections(decoder_id, *args, **kwargs):

A decoder's corrections. get_corrections(id, return_size, reset) for a decoder configured from a multi_decoder_config: its accumulated observable corrections, as bools, cleared afterwards with reset. get_corrections(id, ticket=None, timeout=None) for a queued decoder: the corrections of the oldest batch not yet collected (or of ticket), waited for.

Clear a decoder's partial shot and accumulated corrections (configured from a multi_decoder_config), or drop a queued decoder's batches and statistics.

def expand_dem_chunks(config: decoder_config) -> Optional[Any]:

Rewrite a chunk-form configuration into the equivalent flat form.

Fills block_size, syndrome_size, H_sparse, O_sparse and D_sparse on config in place from dem_chunks (which carries num_rounds inside the DemChunksSpec), so that a chunk-form configuration can be handed to anything that understands only the flat form. Does nothing to a configuration that is already flat (one with an H_sparse, as this leaves behind), so it is safe to call unconditionally.

Returns the closed DetectorErrorModel the flat fields came from (its error_rates the per-fault priors the phases declared), or None if the configuration was already flat or has no dem_chunks. A spec that cannot be expanded or closed raises RuntimeError naming the decoder.

class KernelNotRunWarning(builtins.UserWarning):
