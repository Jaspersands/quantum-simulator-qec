stabilizer_qec.loom

Loom's Eka model, interpreter, validator and exporters (Entropica Labs' el-loom <https://github.com/entropicalabs/el-loom>_ 0.4.0, ported; Apache License 2.0, see LICENSE in this directory): blocks of stabilizers on a lattice, lattice-surgery operations on them (reset, syndrome rounds, logical measurements and Paulis, grow, shrink, merge, split and their conditionals; on the rotated surface code also the auxiliary CNOT, transversal Hadamard, T and S state injection, move, rotate and the Y-wall phase gate), Loom's other code factories (the repetition chain, with its own grow, shrink, merge and split; the Shor, Steane and five-qubit codes), an interpreter that turns an experiment into a circuit with syndromes, detectors and logical observables (gate for gate Loom's own Stim output, except where Loom's order follows a Python set: there, under the same PYTHONHASHSEED), a validator that checks a circuit against its input and output codes on this package's tableau simulator, and exporters to Stim (this package's Circuit, with the noise of Loom's circuit error models), OpenQASM 3, PennyLane, CUDA-Q, Mimiq and Guppy, with their readings of a run's outcome and Loom's Executor. Loom's module paths work under this package: loom.eka.operations is stabilizer_qec.loom.eka.operations, loom_repetition_code.code_factory is stabilizer_qec.loom.repetition_code.code_factory.

>>> from stabilizer_qec import loom
>>> lattice = loom.Lattice.square_2d((15, 15))
>>> a = loom.RotatedSurfaceCode.create(3, 3, lattice, unique_label="a")
>>> b = loom.RotatedSurfaceCode.create(3, 3, lattice, unique_label="b", position=(4, 0))
>>> eka = loom.Eka(lattice, blocks=[a, b], operations=[
...     loom.ResetAllDataQubits("a"), loom.ResetAllDataQubits("b"),
...     loom.MeasureBlockSyndromes("a"), loom.MeasureBlockSyndromes("b"),
...     loom.Merge(["a", "b"], "m"), loom.MeasureBlockSyndromes("m", n_cycles=2),
...     loom.MeasureLogicalZ("m")])
>>> circuit = loom.eka_to_circuit(loom.interpret_eka(eka))
>>> circuit.num_detectors, circuit.num_observables
(76, 1)

What is not ported: Loom's base and logical operations (they are defined, but the interpreter refuses them), if-else circuits, the Visualizer, cliffordsim and the executor's legacy cliffordsim export, the Tanner graphs, parity-check matrices and the syndrome-circuit algorithms built on them, the Pauli-array algebra of loom.eka.utilities, dumps/loads (asdict and fromdict instead), the converters' operation signatures, and the plugin machinery (entry points and applicator classes; one dispatch table here).
