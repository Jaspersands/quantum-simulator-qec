stabilizer_qec.loom

Loom's Eka model, interpreter, validator and exporters (Entropica Labs' el-loom <https://github.com/entropicalabs/el-loom>_ 0.4.0, ported; Apache License 2.0, see LICENSE in this directory): blocks of stabilizers on a lattice, lattice-surgery operations on them (reset, syndrome rounds, logical measurements and Paulis, grow, shrink, merge, split and their conditionals), an interpreter that turns an experiment into a circuit with syndromes, detectors and logical observables (gate for gate Loom's own Stim output, except where Loom's order follows a Python set of strings), a validator that checks a circuit against its input and output codes on this package's tableau simulator, and exporters to Stim (this package's Circuit), OpenQASM 3, PennyLane and CUDA-Q.

>>> from stabilizer_qec import loom
>>> lattice = loom.Lattice.square_2d((15, 15))
>>> a = loom.RotatedSurfaceCode.create(3, 3, lattice, unique_label="a")
>>> b = loom.RotatedSurfaceCode.create(3, 3, lattice, unique_label="b", position=(4, 0))
>>> eka = loom.Eka(lattice, blocks=[a, b], operations=[
...     loom.ResetAllDataQubits("a"), loom.ResetAllDataQubits("b"),
...     loom.MeasureBlockSyndromes("a"), loom.MeasureBlockSyndromes("b"),
...     loom.Merge(["a", "b"], "m"), loom.MeasureBlockSyndromes("m", n_cycles=2),
...     loom.MeasureLogicalZ("m")])
>>> circuit = loom.eka_to_circuit(loom.interpret_eka(eka))
>>> circuit.num_detectors, circuit.num_observables
(76, 1)

What is not ported: Loom's auxiliary CNOT, transversal Hadamard, move, rotate, Y-wall phase gate and state injection applicators, its base and logical operations, if-else circuits and error models, and the Mimiq and Guppy exporters.

class Block:

A code block: its stabilizers (with the ancillas that measure them), its logical X and Z operators, the syndrome circuits (one per Pauli string by default) and which circuit measures which stabilizer. Validation checks distinctness, commutation, that the logicals anticommute pairwise and only pairwise, and that the independent stabilizers plus the logical qubits make up the data qubits.

class Circuit:

A gate (no sub-circuits; name the operation, channels its wires, duration one tick unless given) or a composite circuit: circuit a tuple of time slices, each a tuple of sub-circuits starting at that tick; a list of circuits becomes consecutive slices, each followed by the empty slices its duration fills. The channels and the duration of a composite circuit are derived from its parts; two circuits are equal when they unroll to the same gates on the same wires, tick by tick (labels and ids aside).
