stabilizer-qec 2.2.0
built with pdoc

stabilizer_qec

A quantum error-correction simulator and decoder, in Rust: Stim's circuit and error-model formats, a bit-parallel sampler, exact and correlated matching, belief-matching, BP, BP+OSD and BP+LSD, Relay-BP, colour-code matching, a search decoder, window decoding, IBM's bivariate bicycle codes and lattice surgery, coherent errors at circuit level, and an exact state vector. Finite comparisons against Stim, PyMatching, ldpc, beliefmatching, IBM's relay_bp, Chromobius and Tesseract use each suite's documented tolerances, tie and platform limits.

pip install stabilizer-qec

Getting started

A memory experiment, sampled and decoded:

>>> import stabilizer_qec as sq
>>> circuit = sq.memory_circuit(distance=3, rounds=3, p=0.001)
>>> circuit.num_detectors, circuit.num_observables
(24, 1)
>>> sampler = circuit.compile_detector_sampler(seed=7)
>>> dets, obs = sampler.sample(10_000, separate_observables=True)
>>> dets.shape, dets.dtype
((10000, 24), dtype('bool'))
>>> dem = circuit.detector_error_model(decompose_errors=True)
>>> predictions = sq.Matching(dem).decode_batch(dets)
>>> failures = int((predictions != obs).any(axis=1).sum())
>>> 0 <= failures < 100
True

The names follow the tools this is checked against, so code written for them mostly carries over: Circuit, compile_detector_sampler and separate_observables are Stim's; Matching, decode_batch and enable_correlations are PyMatching's; BpDecoder, BpOsdDecoder, BpLsdDecoder, error_channel, osd_order and lsd_order are ldpc's.

Circuits

Circuit reads Stim's circuit language: every Clifford gate (H, S and CX natively, the other 46 one- and two-qubit gates as their exact decompositions), resets and measurements in all three bases with inverted targets (!q), Pauli-product measurements and rotations (MPP, MXX, MYY, MZZ, SPP), every noise channel (X_ERROR ... PAULI_CHANNEL_2, E, ELSE_CORRELATED_ERROR, HERALDED_ERASE, HERALDED_PAULI_CHANNEL_1), measurement feedback and sweep bits (CX rec[-1] q, CZ sweep[k] q), MPAD, detectors, observables (of measurement records, and of Pauli targets: OBSERVABLE_INCLUDE(0) X0 Z1), coordinates, TICK, REPEAT, and instruction tags (H[tag] 0), which reach the error model as in Stim. Channels whose cases are disjoint enter an error model only with approximate_disjoint_errors, as in Stim.

Or build one in code, as in Stim: append an instruction at a time (targets as qubit indices, strings such as "rec[-1]", or stim.GateTargets), + one circuit after another, and * one into a REPEAT block.

Circuits written for you: Circuit.generated (Stim's generated memories, character for character), memory_circuit (rotated and XZZX surface codes), BivariateBicycleCode (every code of Bravyi et al.'s Table 3 or any other, the gross code's logical operations), CssCode (any CSS code from its checks, hypergraph products and colour codes, with a memory), the surgery module (Z⊗Z and X⊗X merges, a logical CNOT, merges in a row), and stream_memory (a million rounds of a memory, or of any circuit with a loop, window-decoded as they stream).

Knowing a circuit

Where each fault of the error model comes from, as Stim prints it (explain_detector_error_model_errors, every ExplainedError naming the gate, its targets and the Pauli product or measurement it flips); how few faults defeat the circuit (shortest_graphlike_error and search_for_undetectable_logical_errors, Stim's two searches, on circuits and on models, and DetectorErrorModel.distance(), exact by integer programming with scipy installed):

>>> c = sq.Circuit.generated("repetition_code:memory", distance=3, rounds=2, after_clifford_depolarization=0.01)
>>> len(c.shortest_graphlike_error())
3
>>> print(c.shortest_graphlike_error()[0].circuit_error_locations[0].instruction_targets)
DEPOLARIZE2(0.01) 0 1

Diagrams after Stim's (Circuit.diagram): timeline-text (Stim's, character for character), timeline-svg, detslice-svg, timeslice-svg and detslice-with-ops-svg (one panel per tick of a range), and the matching graph.

Shots

Shots are numpy arrays: one row per shot, bool per detector, or bit-packed uint8 rows (bit k of a row in byte k // 8, at position k % 8: numpy.packbits(..., bitorder="little")), the layout Stim and PyMatching use. Predictions are uint8 0/1 per observable. Files in Stim's six formats (01, b8, r8, hits, dets, ptb64) are read and written by read_shot_data_file and write_shot_data_file; raw measurements come from Circuit.compile_sampler, and faults of a model straight from DetectorErrorModel.compile_sampler.

Decoders

On a detector error model, each with decode and decode_batch (any thread count) and pickling:

  • Matching (plain decoding on PyMatching's sparse-blossom port, with finite tied-selection parity checks); correlated decoding requires an unedited DEM/circuit loaded with enable_correlations=True and actual observable IDs 0–63; ensured wider output is zero-padded; UnionFind, CollisionClustering and LocalClustering (Riverlane's hardware union-finds, the second with its leakage-adaptive pre-growth); BeliefMatching; WindowMatching (sliding or parallel windows): for models whose faults set off at most two detectors, or decomposed;
  • BpOsd and BpLsd (ldpc's corrections), RelayBp (IBM's), SearchDecoder (Tesseract's A*, exact on request), AmbiguityClustering (Riverlane's, from its paper): for any model, such as the gross code's;
  • ColorMatching (Chromobius's): colour codes whose detectors carry its colour annotation (CssCode.color_code(d).memory_circuit(..., annotate_colors=True));
  • CompositeDecoder (a model's independent parts, decoded apart by any of these) and SubgraphDecoder (qLDPC's: chosen detector subgraphs, predictions combined); ArgumentReweighting (post-selection: decode again with the correction made less likely, keep the shot if the answer holds) around matching, union-find, BP+OSD, BP+LSD or Relay-BP; LeakageAwareDecoder (leakage heralds raising the priors of the faults a leak makes likely) around the same, or local clustering.
  • PreDecoder (NVIDIA's AI pre-decoder: a 3D convolutional network on the detectors' grid removes the faults it is confident of, and matching or any of these decodes the rest), trained here, in Rust or numpy, with weights for the rotated memory.

On a check matrix, with ldpc's arguments: BpDecoder, BpOsdDecoder, BpLsdDecoder, and RelayBpDecoder with IBM's. tools/decoder_check.py holds each against its authors' package.

stabilizer_qec.conformance (Shen and Zhong's conformance checks, arXiv 2609.07035) checks what counting logical errors cannot: that a decoder's correction explains the syndrome, and that the same instance presented otherwise (faults reordered, detectors renumbered, faults split, weights scaled) gets an answer as good, holding each decoder to what it declares (this package's answer every capability question) and certifying, with no solver, any answer shown not minimum-weight.

Beyond Pauli noise

Coherent errors are tagged identities that Stim reads as identities, so circuits stay Stim's: I_ERROR[R_Z(theta=0.01)] 0, II_ERROR[R_ZZ(theta=0.02)] 0 1, any Pauli product as I_ERROR[R_PAULI(theta=…, pauli=XZY)] 0 1 2. Circuit.compile_coherent_sampler gives shots of the twirled circuit with weights from its interference class. Whole completed-kernel sums recover the coherent distribution in floating-point arithmetic; budget truncation and skipped completion are approximations (see Circuit.compile_coherent_sampler):

>>> c = sq.Circuit("RX 0\nI_ERROR[R_Z(theta=0.2)] 0\nI_ERROR[R_Z(theta=0.15)] 0\nMX 0\nDETECTOR rec[-1]")
>>> d, o, w = c.compile_coherent_sampler(seed=1).sample(100_000)
>>> rate, err = sq.weighted_rate(d[:, 0], w)
>>> abs(rate - 0.1176) < 0.003   # sin²(0.35): the angles add, not their twirls
True

compile_exact_sampler and exact_distribution run the state vector (up to 24 qubits; also T, U3, amplitude and phase damping and T1/T2 relaxation, I_ERROR[THERMAL_RELAXATION(t=…, t1=…, t2=…)]). The command line

stabilizer-qec (or python -m stabilizer_qec) takes Stim's commands and flags (gen, sample, detect, m2d, analyze_errors, sample_dem, convert, explain_errors, diagram) and gives Stim's bytes wherever Stim's output is deterministic, plus decode:

stabilizer-qec gen --code surface_code --task rotated_memory_z --distance 5 --rounds 5         --after_clifford_depolarization 0.001 > c.stim
stabilizer-qec detect --in c.stim --shots 1000 --out_format b8 > d.b8
stabilizer-qec analyze_errors --in c.stim --decompose_errors > c.dem
stabilizer-qec decode --dem c.dem --in d.b8 --in_format b8

Many processes, and sinter

Circuits, error models, converters and decoders pickle and copy, so they cross into multiprocessing and concurrent.futures workers (a decoder is rebuilt there from its model and options). A sampler does not: send the circuit and a seed.

stabilizer_qec.sinter is sinter (Stim's tool for sweeps of decoding experiments), whole: tasks collected by worker processes, resumable from CSV, post-selected, fitted and plotted, with sinter's decoders and this package's (matching, correlated_matching, belief_matching, union_find, bposd, bplsd, relay_bp, color_matching, search):

from stabilizer_qec import sinter

stats = sinter.collect(tasks=tasks, decoders=["pymatching", "bposd"], num_workers=8,
                       max_shots=100_000)

From the command line: stabilizer-qec sinter collect ... (or python -m stabilizer_qec.sinter). With sinter itself, custom_decoders=sinter.sinter_decoders() adds this package's decoders under sq_ names.

Promises

  • Seeds reproduce. Within a documented sampler/version contract, a seed and shot position reproduce shots across supported thread counts (threads=0 is every core). Algorithm corrections can change seeded outcomes; 2.2's coherent proposal/arithmetic corrections do.
  • Errors are errors. Core validation uses ValueError or TypeError; ports may raise documented upstream exception types. Crashes and hangs are bugs to report, not a supported response. Resource checks do not make every allocation or OS memory failure recoverable.
  • Limits. Qubit indices up to 224 - 1, as in Stim. An error model folds the loops that repeat, as Stim folds them, so a d = 11 memory of 10,000 rounds is analysed in a tenth of a second; a decoder unrolls its model, up to 224 faults and declarations. The m2d converter holds a circuit unrolled, up to 2**24 instructions and targets; the sampler runs loops without unrolling them. Generated circuits are written out round by round, up to 10,000 rounds.
  • Stability. Semantic versioning: everything importable from stabilizer_qec without a leading underscore follows the compatibility policy, with corrections and migration changes documented in the changelog. A name is deprecated (with a DeprecationWarning naming its replacement) for at least one minor release before a major release removes it. stabilizer_qec._core is the engine's extension, used by the repository's own tools, and carries no such promise.

The explainer: https://qcompiler.jaspersands.com. The source, the technical report and the changelog: https://github.com/Jaspersands/quantum-simulator-qec.

class LeakageAwareDecoder(stabilizer_qec._decoders._DemDecoder):

Leakage-aware decoding from heralds (Deltakit's LeakageFlags, Google's and Riverlane's leakage-aware decoders), around matching, union-find, BP+OSD, BP+LSD or Relay-BP. Each measurement record of the circuit is a trigger: one that found its qubit leaked (the leakage sampler's heralds), or a HERALD_LEAKAGE_EVENT that fired, says the qubit leaked some time since its last reset, so every two-qubit gate since may have left its partner fully depolarized, and the faults that makes likely have their priors raised for that shot (to their probability given the leak, combined with their own) before it is decoded once. A shot with no trigger is decoded as the inner decoder decodes it. With graded (the default) the leak came at a uniformly random point of the qubit's g gates since its reset, so the j-th gate's partner is depolarized with probability j/(g + 1); graded=False depolarizes every partner fully (the map of the local clustering decoder's paper, which sets those faults' priors to 1/2 and leaves Relay-BP, with no OSD to fall back on, worse off than without heralds). On a d = 5 memory with Deltakit's leakage at every CX (0.3%), heralds cut matching's logical errors 4 times graded, 2 times not.

Made from the circuit; decodes the detectors of circuit.without_leakage() (shots with the circuit's own detectors are taken too: a detector reading only a herald fires its trigger, and the rest are decoded). decode_batch takes the triggers as heralds (per measurement record, as LeakageSampler.sample gives them) or leakage_flags (per herald, as LeakageSampler.sample_measurements and Deltakit give them). decoder="local_clustering" is LocalClustering.from_circuit, its heralds pre-growing the edges instead. class PreDecoder(stabilizer_qec._decoders._DemDecoder):

A convolutional pre-decoder in front of a global decoder, in the shape of NVIDIA's (Chamberland, Olle, Li, Thornton and Baratta, arXiv 2604.12841): a fully convolutional 3D network reads the detection events on the grid of the detectors' coordinates (x, y, t) and gives each of the model's graph-like faults a probability; those above threshold are applied (their detection events removed, their observables flipped), and decoder decodes what is left. The prediction is both together. Most faults are isolated, so the global decoder sees a far sparser syndrome.

With reweight (the default for matching and union-find), the global decoder also weighs each fault by the network's probability q: ln((1 − q)/q), and for a fault the network applied ln(q/(1 − q)), the chance that applying it was wrong. At threshold 1/2 that is matching on the whole syndrome with the network's weights, negative ones included, on a sparser syndrome: what the network learnt that matching's own weights do not say (the X and Z halves of a Y fault together, a hook's two edges) reaches the global decoder even where the network is unsure. Without it (the paper's pipeline, and any decoder) the global decoder keeps its own weights.

The model must be decomposed (decompose_errors=True), and every detector needs coordinates (x, y, t) on a regular grid. The network's inputs are, per sector (the components the model's graph-like faults connect: a CSS memory's X and Z detectors, or sectors), its events and where its detectors are; its outputs are the graph-like faults, one channel per kind (kinds: sector, boundary, and the offset from the fault's first detector to its second), at the fault's first detector. Convolutions are local, so weights trained on one model run on another with the same kinds, any distance or number of rounds.

weights are a weights dict, or a file save wrote; without them the network is fresh (hidden filters per hidden layer, cubes of side kernel) and train trains it on the model's own shots. PreDecoder.pretrained loads this package's weights for memory_circuit's rotated memories.

>>> pre = sq.PreDecoder.pretrained(dem)
>>> left, _, applied = pre.predecode(dets, threads=4)
>>> bool(dets.sum() > 3 * left.sum())
True
>>> plain = int((sq.Matching(dem).decode_batch(dets) != obs).any(axis=1).sum())

class CollisionClustering(stabilizer_qec._decoders._DemDecoder):

class LocalClustering(stabilizer_qec._decoders._DemDecoder):

The Local Clustering Decoder (Ziad et al., arXiv 2411.10343: Riverlane's adaptive union-find for an FPGA) on the graph Matching uses. Every vertex keeps a radius, a cluster index (the lowest in its cluster), a parent, a parity and an activity bit, and a controller runs the paper's stages: growing (active vertices' radii step up, to their longest edge), merging (each vertex adopts a lower cluster index across an edge their radii cover, and passes odd parity to its parent), picking (odd roots become active) and syncing (activity spreads through the cluster), merging and syncing repeating while a vertex is busy, until no vertex is active. The covered edges are peeled for the correction.

Its adaptivity engine pre-grows edges: adaptivity maps each trigger to the edges it makes likely, as pairs of detectors (num_detectors for the boundary), and the heralds given to decode_batch say which triggers fired; the clusters form along the pre-grown edges first. LocalClustering.from_circuit builds the paper's map for leakage: a measurement heralded leaked means its qubit may have leaked any time since its last reset.

Without pre-grown edges its clusters are union-find's and its predictions are CollisionClustering's, shot for shot. Unweighted by default, as the hardware is; weighted=True scales each edge's weight to at most weight_resolution steps (the paper's weighted software decoder). The model must be decomposed.

def search_for_undetectable_logical_errors( self, *, dont_explore_detection_event_sets_with_size_above: int, dont_explore_edges_with_degree_above: int, dont_explore_edges_increasing_symptom_degree: bool, canonicalize_circuit_errors: bool = False, max_memory_bytes: Optional[int] = None) -> list:

Stim's search keeps every set it visits for as long as it runs. def compile_coherent_sampler( self, *, order: int = 3, seed: Optional[int] = None, pairs: bool = False, max_complete: int = 50000, max_contraction: int = 65536) -> CoherentSampler:

A sampler for circuits with coherent errors (I_ERROR[R_Z(theta=0.02)] 0, II_ERROR[R_ZZ(theta=0.01)] 0 1, any Pauli rotation): shots of the Pauli-twirled circuit, as the detector sampler draws them, each with a weight that puts back the interference included in the selected class sum. When the completed kernel is summed whole, this recovers the coherent distribution in floating-point arithmetic; truncated or incomplete sums are approximations. Estimate a rate as (w * hit).sum() / w.sum().

The interference runs between fault sets no record tells apart, a linear space (the circuit's spacetime kernel). Its generators are found locally (a fault either side of a gate, a stabiliser's worth of faults) and then completed to a basis of the whole kernel by one elimination over the rotations' effects: the completion holds what no local search finds, above all a logical error at one time with the same logical at another, whose amplitudes add (coherent logical errors accumulate across rounds). num_nonlocal_generators counts them. A successful contraction sums its whole class, every product of the generators (and of the groups of rotations that are one fault in several places), in floating-point arithmetic (exact_weights): the sum is a product of small factors (each rotation's, a phase that is a quadratic form in the generators, the shot's signs), contracted one generator at a time in O(k·2^w) per shot, w the contraction_width (3 on a d = 3 surface memory over three rounds, 9 at d = 7 over seven). max_contraction caps the contraction's tables (entries in all, 2^16 by default; 0 turns it off; a budget past 2^31 is 2^31, and no table spans 32 or more generators at any budget): past it, and with more than twelve generators, a shot sums the products of up to order generators its faults touch, a truncation, and the sampler warns with an entry lower bound, not a guaranteed sufficient budget, or says that the selected plan cannot fit any budget up to 2^31. Width depends on the selected completed basis and elimination heuristic, not an optimum over equivalent circuits. Building a successful plan can dominate compilation. Sampling scratch per active worker is 24*(arena+largest) bytes before factors and other overhead (arena=entries/2; at most 36*entries), so the entry budget is not a byte limit. Summation can change last bits even with at most twelve generators. Corrected merged proposals and normalized group arithmetic can change seeded shots, including with max_contraction=0. max_complete is the most rotations whose kernel is completed; past it the generators are the local ones only, interference between distant faults is left out, kernel_complete is False and the sampler warns.

A circuit with non-Clifford gates too (I[T] 0, I[R_Z(theta=…)] 0, I[U3(…)] 0: Clifford+T circuits, magic-state injection, a cultivation check) gets the joint sampler: the gates run exactly, as the stabilizer-rank sampler runs them, the errors are drawn as their twirl, and each shot's weight is the coherent probability of its class over the twirl's, every member of the class a re-run of the exact engine with the member's errors inserted and the shot's outcomes forced. Neither the coherent sampler (a Clifford reference circuit) nor a stabilizer-rank sampler alone (cost exponential in the errors) covers this. pairs has the joint sampler sum the products of every two of its generators besides (quadratic in their number: a check on small circuits; the coherent sampler of a Clifford circuit ignores it). def perturbative_distribution( self, order: int = 1, *, symbolic: bool = False, degree: Any = None, max_terms: int = 4194304) -> dict:

The outcome distribution summed over every set of at most order faults, as QuantumClifford.jl's petrajectories: {(detection events, observable flips): weight}, keyed as exact_distribution. Each noise channel (a Pauli channel on a qubit or pair, a measurement's flip, a herald, a chain of correlated errors) is a site that makes none of its faults or one; a fault set's weight is its exact probability, its faults' probabilities times every other site's probability of none. The weights are lower bounds, short of the exact distribution by O(p^(order+1)), and equal to it once order reaches the number of sites. A fault counts toward the order whether or not it changes an outcome, as in QuantumClifford.

With symbolic, each weight is a numpy.polynomial.Polynomial in a noise scale x, every fault's probability p read as p·x (a correlated chain's faults too, each with its probability of happening), cut at x^degree (order by default; "full" keeps every power, as QuantumClifford's symbolic expansion): up to x^order its coefficients are the exact Taylor coefficients of the outcome's probability. The polynomials are in the monomial basis, so with many sites at noise that is not small a full expansion's coefficients grow and alternate, and evaluating it far from x = 0 cancels away its digits (the numeric expansion at full order has no such loss).

For Clifford circuits with Pauli noise whose detectors and observables are deterministic, of any size: each fault's effect is found once, by a Pauli frame per fault carried through the circuit together, and the sum is a dynamic program over outcomes (at most max_terms outcome and fault-count pairs at once).

>>> import stabilizer_qec as sq
>>> c = sq.Circuit("R 0 1\nX_ERROR(0.1) 0 1\nCX 0 1\nM 1\nDETECTOR rec[-1]")
>>> d = c.perturbative_distribution(order=1)
>>> round(d[((True,), ())], 6)  # one X on either qubit: 2 * 0.1 * 0.9
0.18
>>> d = c.perturbative_distribution(order=2, symbolic=True)
>>> [round(float(a), 12) for a in d[((True,), ())].coef]  # 2 (0.1 x) (1 - 0.1 x)
[0.0, 0.2, -0.02]

class SearchDecoder(stabilizer_qec._decoders._DemDecoder):

A search for the most likely error, Tesseract's A* (Beni, Higgott and Shutty, Google, 2025), for any detector error model: states are sets of faults, expanded cheapest first by their weight plus an admissible estimate of explaining the detectors still lit, each grown only by faults through its first lit detector in a detector order. beam drops states lighting more than that many detectors above the fewest seen (None: no beam); no_revisit_dets skips patterns of lit detectors already expanded (faster, not exact); pqlimit bounds the queue (None: no bound); the search runs once per detector order (det_orders, or num_det_orders generated by det_order_method, "index", "bfs" or "coordinate", from seed) and keeps the cheapest answer. Defaults are Tesseract's. With no beam, no queue bound and no_revisit_dets=False it is exact.

Answers equal to the tesseract_decoder package's for the same detector orders (both break ties between equally promising states as the platform's C++ library does; index orders are generated as Tesseract does, the others are this package's own). A shot the search gives up on predicts no flips; return_low_confidence says which. Unlike this package's other decoders on a model, it takes a model of any number of observables, as Tesseract's does.

class WindowMatching(stabilizer_qec._decoders._DemDecoder):

Window decoding (Skoric et al.; Tan et al.): the model cut into overlapping windows of rounds, each matched alone and committing only its middle. mode="sliding" runs them in order; "parallel" decodes alternate windows at once, then the gaps between. Each window commits commit rounds with buffer rounds on either side. The model's detectors need a time coordinate (their last), as Stim's generated circuits give them.

A long model is not unrolled: with template=True (and by default, for a model of more than a million faults with a loop), the windows' graphs come from a short template of the model's longest loop, whose middle windows serve every window away from the model's ends, shifted. Shots are still given whole, so a d = 11 memory of 10,000 rounds decodes from its folded model. template=False cuts every window from the whole model; both give the same predictions. With a template, return_timings times the first shot of each 64 (the rest are NaN).
